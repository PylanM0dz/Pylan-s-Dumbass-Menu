## About

**Pylan's Dumbass Menu** is a Gorilla Tag mod menu developed by **PylanM0dz**.

Built for players who want to customize their experience, the menu brings together a collection of mods and features in one interface.

- 🎮 A custom in-game menu.
- ⚙️ Multiple mod categories and settings.
- 🎨 Custom menu branding and design.
- 🛠️ Ongoing development and improvements.

Features may change between versions.

## Installation

1. Open the [Releases page](https://github.com/PylanM0dz/Pylan-s-Dumbass-Menu/releases).
2. Download the latest available release.
3. Follow the installation instructions provided with that release.
4. Launch Gorilla Tag and check that the menu loads correctly.

Make sure you use a version compatible with your game and mod loader.
